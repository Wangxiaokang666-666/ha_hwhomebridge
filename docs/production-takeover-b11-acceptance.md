## 回退方式与备份

日常引擎回退使用原集成条目的配置入口，选择“接管当前网关”，进入“沿用当前网关：启停与后端切换”，保留目录 `.storage/hwhomebridge/gateways/current`，选择 `legacy`。实际回退已验证，不需要删除网关、重新配对或改旧灯绑定。原 SDK 提供旧设备控制，新增功能卡不属于原 SDK 的能力范围。选回 `openharmony` 后等待原网关和设备重新上线；应以实际活动后端和 `pending` 清空为准，不能只看选项保存成功。

原机保留 b6 冷备、b6 组件备份、b10 组件备份，以及 b11 安装前的完整受管运行目录与注册表。Mac 另有独立副本，b11 回退材料传输前后 SHA256 一致。原配对冷备已做离线校验和全新目录还原验证。

完整退回 b6 与切换原 SDK 是两个层次。b6 文件还原在隔离目录验证过；本轮没有在完成接管后再次把生产组件降回 b6。完整降级需停止所有共享配置写入者，按安装收据逐层恢复 b10、b6 组件及对应条目，不应把旧配对 KV 直接覆盖到正在运行的网关。备份和原始日志含私有资料，存放在仓库外。
